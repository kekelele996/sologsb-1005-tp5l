# 专利权利要求映射工作台

用于专利代理人与审查人员核对权利要求、技术特征和说明书支持依据的前端工作台。数据按案件本地保存，可恢复上次工作位置。

## 功能

- 录入独立/从属权利要求与说明书段落。
- 将权利要求拆分为技术特征，设置父级层级、特征间引用和负责角色。
- 为每个特征映射一个或多个说明书支持段落。
- 自动提示引用循环、缺少依据、空特征和“特征已删除但映射未清理”。
- 角色切换与批注隔离：代理人、审查员只能修改本人批注，观察者只读。
- 全量操作撤销重做，使用 `Ctrl/⌘ + Z` 与 `Ctrl/⌘ + Shift + Z`。
- 保存权利要求版本，逐项比较正文差异并恢复历史版本。
- 导出完整 JSON 或可核对的 CSV，本地保存上次标签页、特征和滚动位置。

## 技术栈

- Angular 19、TypeScript、RxJS
- PrimeNG 19、PrimeIcons
- 浏览器 `localStorage`

## 本地开发

```bash
npm install
npm start
```

开发服务器监听容器内端口 4200，仅用于本地开发；项目不在源码中定义宿主端口。

## 生产构建

```bash
npm install
npm run build
```

产物位于 `dist/patent-claim-workbench/browser`。

## Docker

```bash
docker build -t sologsb-1005 .
docker run --rm -p 10005:80 sologsb-1005
```

nginx 在容器 80 端口提供构建产物，并按根端口表映射到宿主 `10005`。

## 数据说明

数据与版本存在浏览器本地，按崩溃可恢复日志（WAL）组织：

- **恢复点先行**：每轮修改先把「上一轮完好状态 + 本轮状态 + 撤销/重做栈」写入恢复日志并读回确认，再写主数据信封，全部确认后闭合日志。浏览器在自动保存途中被关闭，两份状态都在。
- **重开恢复**：发现未闭合的恢复点时，工作台停在上一轮完好状态（案件不会空白），弹窗列出中断轮次将找回的权利要求、特征映射、批注、版本数量与最近轮次，代理人可「找回中断前进度」或「放弃该轮」。找回后撤销/重做从该轮之后继续，重做栈清空。
- **损坏隔离**：写坏的 JSON 不会被静默覆盖或回退成空案，原文移入隔离区，可在恢复弹窗中导出或清除；另有上一代完好信封作为备份兜底。
- **安全写入**：所有保存执行「序列化 → 写入 → 读回逐字节比对」，配额不足或被截断时横幅告警、支持手动补存，内存中的编辑不丢失。
- **旧格式接入**：v1 裸数据首次打开自动迁移为信封格式，迁移成功后才删除旧键。

存储键：主数据 `…-workbench-v2`、恢复日志 `…-recovery-journal-v1`、信封备份 `…-envelope-backup-v1`、隔离区索引 `…-quarantine-v1`。若需团队共享或长期归档，请在后续接入后端存储；当前实现为明确的前端离线原型。
